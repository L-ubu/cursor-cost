02What you get

◆ No admin key needed

Uses the same dashboard endpoints your browser uses. If you can open cursor.com/dashboard/usage, you can run this.

◆ Self-renewing session

Every response's Set-Cookie is persisted back to the jar, so the session rolls forward with use. A dead session is a 30-second re-copy.

◆ Never double-counts

Events are deduped on (timestamp, model, tokens, cost). Overlapping fetches, re-runs and pagination overlaps are all safe.

◆ Budget bar with projection

Month-to-date spend, daily average, projected end-of-month cost, and a bar that turns red before your wallet does.

◆ Daily sync via launchd

cursor-cost install-schedule fetches every morning at 08:30 and pings you with a macOS notification if auth ever dies.

◆ Data stays local

Everything lives in ~/.cursor-cost/. The only network traffic is to cursor.com itself. --json for piping anywhere else.

04How it works

The decisions worth knowing about, written down.

Your cookie, your machine

cursor-cost login opens your installed browser with a fresh profile — you log in yourself, MFA and all, and the script only reads the resulting cursor.com cookies into ~/.cursor-cost/ (0600). The dashboard's usage table is loaded client-side from /api/dashboard/get-filtered-usage-events; cursor-cost calls the same endpoint, with CSV export and HTML scraping as fallbacks. No credentials are stored, nothing is proxied.

The jar renews itself

WorkOS sessions roll with activity. Every fetch persists response cookies back to ~/.cursor-cost/data/session.json, so running the tool is what keeps it authenticated. The daily launchd job exists for exactly this reason.

Dead sessions fail loud, not silent

Absolute expiry, logout or a password change kills the session for good. The tool detects the redirect, fires a macOS notification, and prints the 30-second fix — instead of letting you find out at month-end.

Included vs on-demand, always split

Only on-demand rows cost real money. Included usage is shown for context — tokens, models, trends — but the budget bar tracks what actually bills you.
